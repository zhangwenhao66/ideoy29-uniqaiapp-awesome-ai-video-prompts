# Security

This repository contains prompt text, Markdown and dependency-free Python scripts that read local JSON. It makes no network calls and stores no credentials.

If you find something that looks like a security issue (for example a script that could be made to read or write outside the repo, or a prompt that embeds instructions aimed at an agent), email support@uniqai.app with the file path and a short description. Please do not open a public issue for it until it is fixed. You will get a reply within a few working days.
